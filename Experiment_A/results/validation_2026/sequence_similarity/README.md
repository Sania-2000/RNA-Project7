# Sequence-Similarity Validation

This directory contains exploratory sequence-similarity analyses for the 45-RNA Experiment A sensitivity dataset.

All 45 RNA sequences were distinct, with no exact sequence duplicates.

An all-versus-all BLASTN screen identified 10 high-similarity RNA pairs using thresholds of at least 80% sequence identity, 70% coverage of each sequence, and 20 aligned nucleotides. All 10 pairs were found within the same supplementary sections, with no cross-section pairs passing these thresholds.

These findings support the existing supplementary-section grouping for the detected high-similarity relationships. However, the screening does not establish evolutionary-family independence, because more distant homologous relationships may remain undetected.
