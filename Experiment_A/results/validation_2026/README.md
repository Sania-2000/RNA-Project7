# Experiment A — Additional Validation

This directory contains supplementary validation and reproducibility evidence for Experiment A.

The analyses include grouped-bootstrap reproduction, exploratory sequence-similarity screening, RNA3DB metadata mapping, an alternative 26-group sensitivity analysis, and post-hoc calibration verification.

These analyses complement the original structural-calibration evaluation. The supplementary-section groups have not been established as independent evolutionary families, and complete independence from predictor training datasets remains unverified.
